# GTK real input-method qualification

Implementation: `528680b` normalizes GTK letter identities for shared shortcuts;
`2f53f9b` gives the input method first ownership of keyboard events and adds the
isolated real-engine fixture. `e29e7a3` restores focus when a selected native
terminal tab maps. Tests exercised the source subsequently committed at these
revisions; documentation commits do not change that implementation.

## Environment and dependency boundary

Ubuntu 24.04 x86_64 container, GTK 4.14.5, libadwaita 1.5.0, Sway 1.9 with its
headless/pixman backend, wtype virtual keyboard, software Vulkan/GL. The IBus
daemon and GTK4 module are distribution 1.5.29-2 packages; libpinyin is 1.15.7.
Each run owns its D-Bus session, home, configuration, runtime, compositor, input
service, keyboard and raw PTY child. No host input source or desktop settings
are changed.

The stock IBus 1.5.29 client fails cancellation in GTK4 synchronous mode: it
ignores the hide-preedit reply and prints `Type 'h' is not supported`. This
matches [the upstream issue](https://github.com/ibus/ibus/issues/2596). Kiwi's
original routing additionally leaked Escape to the PTY before the engine saw
it. Fixing Kiwi removes that leak but does not repair the external library.

Synchronous qualification therefore loads the pinned upstream 1.5.31 client
library into **Kiwi only**, while retaining the distribution daemon, module and
engine. `script/build-ci-ibus-client` downloads the release archive, checks its
SHA-256, and builds/installs only its `src` directory in an explicit private
prefix. This exact helper was executed locally. Separate successful runs use
the stock client with IBus hybrid mode (`IBUS_ENABLE_SYNC_MODE=2`), which exercises
nested main-loop dispatch. No application default is changed.

## Assertions

- Type `nihao` through real Wayland keys and libpinyin; observe native preedit,
  then assert the PTY receives exactly UTF-8 `你好` after Space.
- Assert composing text produces no PTY bytes. Escape cancels in both legacy
  and Kitty flag-31 modes without leaking a press or release.
- In flag-31 mode, composition produces exactly `\x1b[0;;20320:22909u`; ordinary
  `a` after switching to the US engine retains associated text and its release.
- Open Find with a real shortcut, compose its Unicode query, cancel a second
  composition without closing Find, then close Find. No query bytes reach the
  child. Ctrl-C subsequently produces exactly byte 3.
- Move to another compositor workspace during preedit, verify cancellation,
  return and successfully compose again.
- Fail on GTK critical errors, early critical-process exit or expired deadlines.

The controller and PTY are real. The observer wraps callbacks to record them;
only the terminal's negotiated Kitty mode is set directly by the fixture.
The test does not inject preedit or commit callbacks. A single virtual-keyboard
client spans each composition/cancellation sequence, because replacing its
keymap between separate wtype processes can itself reset GTK composition.

The new gate is configured in Linux CI for WGPU, GL, GL native tabs and the
hybrid-dispatch case. Hosted CI has not been run from this session.

All four configurations pass locally. Native tabs additionally pass three
consecutive complete runs after fixing initial focus. The old path could leave
focus on `AdwTab`, with a mapped, sensitive terminal receiving no keys. An
immediate focus request alone was intermittent: the selected content had not
necessarily mapped yet. The fix remembers that focus request until the selected
terminal's map signal; it adds no recurring timer.

Both macOS and Linux pass `make check`: 659 Lua tests across 130 suites, 18 PTY
tests and a 373-file Lua syntax check. Linux's strict GTK bridge build, the X11
input/correlation smoke and the complete Wayland PRIMARY matrix also pass.

Transcripts: [WGPU](2026-10-26-gtk-ime-wgpu.log),
[GL](2026-10-26-gtk-ime-gl.log), [native tabs](2026-10-26-gtk-ime-tabs.log),
[stock-client hybrid mode](2026-10-26-gtk-ime-hybrid.log).

The latter used a temporary diagnostic getter to record GTK's actual focus
widget; that getter is absent from the final bridge.

## Reproduction

Install IBus, its GTK4 module, libpinyin, Sway and wtype along with Kiwi's native
dependencies. On Ubuntu 24.04, build the private fixed client first:

```sh
./script/build-ci-ibus-client "$PWD/.build/ibus-client"
KIWI_IME_CLIENT_LIBRARY="$PWD/.build/ibus-client/lib" \
  IBUS_ENABLE_SYNC_MODE=1 make gtk-ime-wayland-smoke
```

Set `KIWI_GTK_PRESENTER=gl` for GL, and additionally `KIWI_GTK_NATIVE_TABS=1` for
native tabs. To test the distribution client with nested dispatch, omit the
client override and set `IBUS_ENABLE_SYNC_MODE=2`. Select the installed lavapipe
ICD with `VK_ICD_FILENAMES` when software Vulkan is needed.

## Limits

This qualifies one Chinese engine and specific GTK/Wayland workflows. It does
not establish candidate-window placement, physical keyboard layouts, other
compositors, Japanese/Korean/dead-key workflows, Cocoa IME or screen readers.
The default GLFW/Wayland path still lacks a composition bridge. Scaling,
monitor transitions, suspend/resume and broader desktop qualification remain
open. [Input ownership contract](../adr/0049-gtk-input-method-key-ownership.md).
