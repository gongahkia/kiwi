# Orca reading-command qualification, 2026-10-27

At clean revision `9192e9a1f27bd5ce61dc46c3622d21c649cc0fb2`, both the
[GTK WGPU](2026-10-27-orca-wgpu.json) and
[GTK GL](2026-10-27-orca-gl.json) fixtures passed on the owned Ubuntu 24.04
container. Versions were GTK 4.14.5, AT-SPI 2.52.0 and Orca 46.1. Each run used
its own D-Bus session, Xvfb display, Openbox window manager, HOME, XDG directories
and Orca preferences. No user desktop or accessibility setting was changed.

The fixture launches the actual Kiwi application and a raw PTY child, then uses
XTest keyboard input through xdotool. An independent AT-SPI client checks the
terminal projection, while the real Orca process consumes reading commands and
generates speech. Both runs passed these additional assertions:

| Action | Required generated speech / behavior |
| --- | --- |
| `KP Enter` (Where Am I) on terminal text | Exactly `beta é`, preserving the combining accent; Orca's log identifies its command handler |
| Default shortcut opens the command palette | Speech identifies `Command Palette`; the external client verifies the editable query and subsequent focus restoration |
| Enter vi mode, select `upd`, then `Insert+Shift+Up` | Exactly `Selected text is: upd`; Orca's selection command handler executes and the selection stays unchanged |

The original protocol checks also pass: character counts and character/word/line
ranges (including CJK and combining marks), caret offsets, read-only/multiline
states, no unchanged-text event churn, selection events, palette dismissal,
palette action dispatch and terminal exit. The unchanged Wayland routes passed
on both presenters during development of the X11 extension.

## Instrumentation and boundaries

Orca's supported private `orca-customizations.py` hook only enables line-buffered
debug output. Its default file buffering initially hid a correct utterance until
shutdown; the fixture now observes it while the reader is running. No event
handler, accessibility query, command implementation or speech-generation
function is replaced. The fixture waits for Orca to observe the actual selection
before issuing the read-selection command. It requires both the handler log and
the exact utterance, preventing a coincidental focus announcement from passing
a command assertion. The fixed locale is `C.UTF-8`.

Speech-server autospawn is disabled. Orca's normal no-server path records generated
utterances, so this verifies speech generation, **not audible synthesis**. Braille,
flat-review geometry, magnifier placement, physical keyboards, Wayland reader
integration, VoiceOver and daily usability remain unqualified. Orca 46's keyboard
initialization requires an X11 display; the first Wayland-only attempt failed
before application testing. This is not evidence that Kiwi cannot support a
different reader/version on Wayland.

The owned session has a 180-second outer deadline, bounded tree traversal and
retained diagnostics. Transient null children during GTK palette creation are
ignored during discovery; failures of established-terminal queries still fail.
Failure-diagnostic errors cannot overwrite the original failure. The fixture and
both presenter invocations are included in Linux CI, but these local reports do
not claim a remote CI run.

## Projection allocation regression

Commit `e02ca62` avoids allocating a UTF-8 pattern iterator for single-byte
ASCII cells, which dominate blank viewport padding. A 120×44 viewport containing
ASCII, CJK and a combining mark allocated about 47,442 KiB across 100 projections
before the change and 10,338 KiB afterward on Intel macOS. The test pauses GC
within the measured allocation window and restores it afterward. The new 16 MiB
allocation gate fails against the original module (47,467 KiB in that run) and
passes with JIT enabled and disabled. Unicode character/caret offsets are checked
in the same test. All 681 deterministic Lua tests in 132 suites passed afterward.
These measurements describe transient allocation in this projection workload;
they are not a native responsiveness or whole-application memory comparison.
