# External GTK accessibility qualification, 2026-10-27

The [WGPU report](2026-10-27-gtk-atspi-wgpu.json) and
[single-session GL report](2026-10-27-gtk-atspi-gl.json) passed at clean revision
`732de848b2edd8225de55556bc1a9ab2c80ec503`. These used the owned Ubuntu 24.04
container, GTK 4.14.5, software rendering and a private headless Sway desktop.
Both the `libatspi2.0-0t64` runtime and `gir1.2-atspi-2.0` typelib were
`2.52.0-1build1`, verified with `dpkg-query`. The raw reports' AT-SPI version field
is empty because the initial fallback queried the pre-t64 package name; the
fixture now handles both names. The reports are retained without rewriting that
metadata.

An independent Python AT-SPI client discovered the actual application's terminal
by PID and a PTY-generated title. Real virtual-keyboard input requested the
fixture's text after initial window allocation. Both runs verified 3,254 Unicode
characters, caret offsets 99 and 195 after distinct child output, and five
checkpoints: initial output, restored focus, updated output, vi selection and a
palette action. Both recorded 27 terminal accessibility events.

The checks require:

- Correct CJK and combining-character text, character counts, caret offsets,
  character/word/line ranges, and safe empty attribute queries.
- Read-only, multiline, focusable/focused states, without an editable state.
- No text-change notifications in response to unchanged queries or selection-only
  navigation, followed by fresh text/caret/selection events for actual changes.
- The default command-palette shortcut, accessible query text, Escape dismissal
  with a nonempty query, and restored terminal focus.
- Vi mode entered by its default shortcut, the exact selection `upd`, clearing
  that selection on exit, and actual execution of Toggle Vi Mode from the palette.

The [initial failing report](2026-10-27-gtk-atspi-before.json) exposed an editable
terminal without multiline/read-only states. It came from a dirty checkout
containing the new fixture; it is regression evidence, not clean-source release
qualification. Further test development exposed repeated whole-text events for
unchanged output, unsafe null attribute arrays, combining marks omitted from word
ranges, and dropped modal text commands. The native key bridge now distinguishes
ownership of a physical key from explicit suppression of its committed text.
The single-session GL controller also now opens a palette of actions it supports.

The final fixture isolates the entire D-Bus activation environment before launch,
including home, cache and runtime directories. It enables accessibility only on
that private session and pins both endpoints to its bus. Earlier concurrent runs
shared the launcher's cache socket despite separate session buses; one aborted
and left child processes behind. Those owned processes were stopped. A separate
process group and a 90-second outer deadline now bound cleanup even if libatspi
aborts Python. Discovery clears cached tree entries and retries transient replies
within its existing ten-second deadline; established-terminal queries remain
strict. The final retained runs were sequential and had no recorded discovery
errors. GTK still emitted an initial missing-cache warning during registration.

Regression validation also passed `make check` (666 Lua tests across 131 suites,
PTY integration, fuzz, watcher, benchmark-budget, regex, terminfo and source
checks), the native GTK build/ABI and input smoke, and real IBus/libpinyin
workflows on WGPU, single-session GL and tabbed GL. The latter found a test-control
file race on shutdown; publishing complete commands by atomic rename resolved it.

This does not qualify Orca speech/braille, magnifier geometry, locale-aware
segmentation, physical desktop focus policies, every input method, monitor
hotplug or system sleep. GTK's generic editable-text bridge also needs an explicit
end offset on this version; the palette test uses its character count, as
documented in [the accessibility contract](../ACCESSIBILITY.md). Large-history
memory qualification remains separately [incomplete](2026-10-27-full-history.md).
