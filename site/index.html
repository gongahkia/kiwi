kumeyuri

A Rust renderer that turns vanilla Mermaid into animated terminal, SVG, raster, and browser artefacts from one frame stream.

Install Try playground View source Launch notes

Install

Use the CLI, npm browser package, or static GitHub Action.

CLI

cargo install kumeyuri
kumeyuri render diagrams/flow.mmd --format svg \
  --theme github --dark-theme tokyo-night > public/flow.svg

Browser

npm install kumeyuri

import initWasm, * as wasm from "kumeyuri/wasm";
import { defineKumeyuriElement, initKumeyuri } from "kumeyuri";

await initKumeyuri({ ...wasm, default: initWasm });
defineKumeyuriElement();

Static Sites

kumeyuri render docs/diagram.mmd --format webp > public/diagram.webp
kumeyuri compat --json > public/kumeyuri-compat.json

Outputs

One parser, one animation timeline, many renderers.

  • TUILive playback for terminal-first docs and demos.
  • SVGFrame groups, SMIL, CSS fallback, text metadata.
  • RasterGIF, APNG, and WebP for feeds and slide decks.
  • WASMA typed wrapper and custom element for browser embeds.

Embed

Ship static assets by default; use WASM when runtime controls matter.

<picture>
  <source srcset="/diagrams/flow.webp" type="image/webp">
  <img src="/diagrams/flow.svg" alt="Request flow">
</picture>

<kumeyuri-diagram
  src="/diagrams/flow.mmd"
  animate="trace"
  theme="github"
  dark-theme="tokyo-night"
  max-source-bytes="200000"
  fetch-timeout-ms="5000"
  lazy
  csp
  autoplay
  controls
>
  <svg role="img" aria-label="Request flow fallback"></svg>
  <noscript><img src="/diagrams/flow.svg" alt="Request flow"></noscript>
</kumeyuri-diagram>

Static SVG/WebP works without JavaScript. The custom element adds playback controls, reduced-motion handling, CSP styling hooks, lazy rendering, fetch timeout, and source-size caps.

Build-Time Plugins

Render at build time for MDX, Markdown, and framework docs.

  • remark / rehypeTransform Mermaid fences into generated SVG or text during Markdown builds.
  • Docusaurus / AstroInject static assets by default and opt into the WASM player only for interactive pages.
  • mdBookUse `mdbook-kumeyuri` for reproducible book builds.
  • GitHub ActionRender changed diagrams in CI and commit verified assets.

Distribution Trust

Designed for pinned, verifiable website deploys.

Publish artifacts should include npm provenance, release checksums, SBOM output, and SRI hashes for static browser assets. This site ships a generated `integrity.json` manifest for the checked-in browser files.

npm pack --dry-run
npm run integrity:site
cargo audit
cargo deny check
scripts/check-wasm-budget.sh
shasum -a 256 site/pkg/*
