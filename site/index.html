kumeyuri

A Rust renderer that turns vanilla Mermaid into animated terminal, SVG, raster, and browser artefacts from one frame stream.

View source Embedding guide Launch notes

Current repo workflow

Render one source into multiple surfaces.

cargo run -q -p kumeyuri-cli -- render site/assets/hero.mmd \
  --format svg --theme github --dark-theme tokyo-night > site/assets/hero.svg
cargo run -q -p kumeyuri-cli -- render site/assets/hero.mmd \
  --format gif --padding 12 > hero.gif
cargo run -q -p kumeyuri-cli -- play site/assets/hero.mmd --loop

Outputs

One parser, one animation timeline, many renderers.

  • TUILive playback for terminal-first docs and demos.
  • SVGFrame groups, SMIL, CSS fallback, text metadata.
  • RasterGIF, APNG, and WebP for feeds and slide decks.
  • WASMA typed wrapper and custom element for browser embeds.

Embed

Drop generated diagrams into READMEs, docs, and static sites.

<kumeyuri-diagram
  src="/diagrams/flow.mmd"
  animate="trace"
  theme="github"
  dark-theme="tokyo-night"
  autoplay
  controls
></kumeyuri-diagram>

Static SVG works without JavaScript; the browser component adds playback controls when the WASM bundle is loaded.
