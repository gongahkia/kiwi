# wat for Microsoft Teams

## Short Description

Search acronyms and team jargon in Microsoft Teams.

## Full Description

wat helps teams search public technical acronyms and team-specific jargon from the Teams compose box or command box. The Teams app uses an API-based message extension with one search command and returns Adaptive Cards containing the term, expansion, meaning, layer, and confidence.

## Privacy Summary

The Teams app sends only the explicit search text entered into the message extension. It does not request channel history, message content, or write access.
