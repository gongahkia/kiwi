# wat

wat explains acronyms and team jargon in Slack.

## Short Description

Look up technical acronyms and team-specific shorthand from Slack.

## Long Description

wat helps teams decode overloaded acronyms, public tech terms, and team-local jargon without leaving Slack. Use `/wat <term>` for a direct lookup, message shortcuts to explain acronyms in a selected message, and admin commands to add team-specific definitions after review.

Each result is designed to include the top expansion, domain labels, confidence tier, and source citations. Team overlays can sit above the public corpus so local meanings win where they should.

## Privacy Summary

wat should process only explicit commands, selected message text, mentions, or opted-in channel detection candidates. Channel history ingestion is not enabled by default.
