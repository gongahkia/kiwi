# Tikrit

A compact Love2D prototype: a Doom-style raycast maze where a single pathfinding enemy hunts the player through a freshly generated layout.

## Run

```sh
love .
```

## Controls

- `WASD`: move and strafe
- `Mouse`, `Left/Right`, `Q/E`: turn
- `Shift`: sprint
- `M`: toggle minimap
- `N` or `R`: generate a new maze
- `Esc`: toggle mouse capture
