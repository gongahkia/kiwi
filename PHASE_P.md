# PHASE_P.md — Interactivity, Demos, Polish (→ v1.0)

**Goal:** Ship the live tuning UI, A/B split mode, still-snapshot path, and the README-quality demo assets that the launch hinges on. This is the phase that turns a powerful tool into one people *use* and *share*.

**Exit criteria → tag `v1.0`:** an OSD lets users tune `edge-threshold`, `dog-sigma`, `contrast`, `style`, `mode`, `charset` mid-playback; `--split` runs two graphs side-by-side; `--still` writes a snapshot PNG; README's hero GIF is the structure-mode v2 side-by-side demo; man page and `--help` are in parity; tagged release artifacts exist on GitHub Releases and Homebrew.

---

## Architecture decisions locked in this phase

- **OSD is a separate render layer over the bottom 1–3 rows.** Doesn't enter the diff emitter's region; emitted as a fixed-region update after the main emit.
- **A/B split is two graphs in the same process** with the same source, rendered into adjacent rectangles of the CellBuffer.
- **Still snapshot reuses Phase N's `raster_compose` + Phase I's FreeType.** Same code path as MP4 export rasterisation; same outputs.

## §OSD — on-screen-display + live tuning

New `src/osd.{hpp,cpp}`:
- Toggle with `i` (info) or `o` (OSD).
- Bottom 2 rows reserved when active; main render area shrinks by 2.
- Bindings:
  - `[`/`]` — decrease/increase `edge-threshold`.
  - `,`/`.` — `dog-sigma`.
  - `;`/`'` — `contrast`.
  - `c` — cycle `--charset` through bundled presets.
  - `s` — cycle `--style {none, painterly, hatch, stipple, flow}`.
  - `m` — cycle `--mode` through valid rungs on the current terminal.
  - `f` — cycle `--glyph-features {overlap, hog, sdf}`.
  - `g` — toggle `--gpu`.
  - `?` — show binding list.
- Top-right HUD: current values + fps + dropped frame count (already in `--debug-stats`; reuse).

- **DoD:** changes take effect within one frame; the OSD never bleeds into the diff'd content; quitting cleanly hides it.

## §Split — A/B side-by-side

New `src/split.{hpp,cpp}`:
- `--split a:b` parses two graph names or `--graph a.yaml,b.yaml`.
- Each graph renders its half of the terminal width into the shared CellBuffer (each owns its own cells).
- Vertical seam line drawn between halves (configurable glyph `─` `┃`).
- Arrow keys drag the seam left/right; the two graphs reflow.
- Single source (camera/file) feeds both graphs to keep timing aligned.

- **DoD:** `contourtty clip.mp4 --split luminance:structure` shows luminance left, structure right, with a draggable seam; recorded as the README hero GIF.

## §Still — single-frame PNG snapshot

New `src/snapshot.{hpp,cpp}`:
- `--still PATH.png` (extends existing `--dump-png` semantics from PHASE_G/Phase F).
- Runs the full render graph for the requested frame number (or `--still-at HH:MM:SS`).
- Composes via Phase N's `raster_compose` + Phase I's FreeType.
- Writes via stb_image_write.

- **DoD:** `contourtty clip.mp4 --still hero.png --mode structure --style hatch` writes a PNG that visually matches the live rendered cell at that frame.

## §Launch
- Honest fps numbers in BENCHMARKS.md and the launch post.
- Name the terminal used (Ghostty or Kitty) and the font (bundled).
- Don't oversell: structure mode is a *visible* improvement on most footage; pixel mode on Kitty is for terminals that can do it; nothing here magically makes 1080p run at 60 fps on every terminal.
- Tag, release, post.

## Pitfalls
- OSD that uses the diff emitter's region → re-emission churn. Reserve the OSD rows and exclude them from diff scope.
- Split mode with separate sources → out-of-sync video. Use one decoded frame for both graphs.
- Still-snapshot uses a different font/metric path from the live renderer → snapshot doesn't match what user saw. Share `raster_compose` between live, snapshot, and MP4 export.
- Man page and `--help` drift is the most common projects-of-this-shape failure mode. Generate both from one source.
- Releasing Homebrew bottle without re-running tests on the bottle → broken installs. Verify in the release pipeline.
- Don't ship the launch with Phase H–O half-finished. Each tag (`v0.9` end of L, `v0.95` end of N, `v1.0` end of P) is gated on its phase exit criteria.
