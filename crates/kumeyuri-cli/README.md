# kumeyuri CLI

Command-line interface and local MCP server for kumeyuri.

- MCP Registry name: `mcp-name: io.github.gongahkia/kumeyuri`

Run the stdio MCP server:

```sh
kumeyuri mcp --transport stdio
```

The server exposes tools to render Mermaid source, lint diagrams, list themes,
list supported diagram types, and open kumeyuri timeline playback.

See the repository MCP guide for client configuration:

<https://github.com/gongahkia/kumeyuri/blob/main/docs/mcp.md>
