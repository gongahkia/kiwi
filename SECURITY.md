# Security Policy

## Reporting a Vulnerability

Report suspected vulnerabilities by email:

```text
angryapplegravy@gmail.com
```

No PGP key is published for vulnerability reports. Do not send encrypted
vulnerability details unless a PGP key is added to this policy.

Include:

* Affected version, commit, or branch.
* Reproduction steps or proof of concept.
* Impact and exploitability notes.
* Any suggested mitigation.

Do not open a public issue for an unpatched vulnerability.

## Supported Versions

kumeyuri is pre-release. Security fixes target `main` until the first stable
release defines a version support policy.

## Response

Maintainers will acknowledge reports within 7 days where possible and will
coordinate disclosure timing based on severity and fix availability.
